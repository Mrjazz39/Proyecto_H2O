# Plataforma Inteligente para Reportes de Agua (Proyecto H2O)

Proyecto del Grupo #1 — Agua. Plataforma web inteligente para reportar, geolocalizar, clasificar, priorizar y gestionar incidentes relacionados con el agua.

## 👥 Integrantes
- **Lorena** — Frontend y UX/UI
- **Axel** — Backend y Base de Datos
- **Gabriel** — IA y Análisis
- **Ivan** — Mapas y Dashboards
- **Kevin** — Integración e Infraestructura

## 🛠️ Stack Tecnológico
- **Frontend:** React + Vite (Lorena)
- **Backend:** Laravel + PHP + MySQL (Axel)
- **IA:** Python + FastAPI (Gabriel)
- **Mapas:** Leaflet + OpenStreetMap (Ivan)
- **Infraestructura:** Docker + Docker Compose (Kevin)
